# МАРС — Кибер-отель

Цифровая площадка кибер-отеля МАРС. React + Vite + TypeScript + Tailwind.
Все изображения на сайте подгружаются динамически по ключевым словам
(см. `src/utils/image.ts`) — в репозитории нет тяжёлых захардкоженных
картинок, сайт при этом выглядит полностью законченным.

## Разделы сайта

- Главная, Номера, Игровой модуль, Услуги
- **Меню** — три рациона (традиционное / халяль / вегетарианское) × завтрак/обед/ужин
- **Депозит и доступ** — тарифы предоплаты (неделя / месяц / год) и генерация QR-кода для бесконтактного заезда
- Партнёр — Fitness Food Factory (официальный спонсор питания)
- О нас, Галерея, Контакты, Бронирование

## Как залить в новый репозиторий на GitHub

1. Скачай и распакуй архив `mars-hotel.zip`.
2. На github.com создай новый **пустой** репозиторий (без README/лицензии),
   например `mars-hotel`.
3. В папке проекта:

```bash
git init
git add .
git commit -m "Initial commit: MARS cyber-hotel site"
git branch -M main
git remote add origin https://github.com/<твой-аккаунт>/mars-hotel.git
git push -u origin main
```

Если работаешь с телефона через GitHub mobile web — можно вместо `git push`
загрузить содержимое папки через кнопку **Add file → Upload files** прямо
в веб-интерфейсе репозитория (перетащить всю распакованную папку).

## Деплой на Vercel

1. Зайти на vercel.com → **New Project** → импортировать репозиторий `mars-hotel`.
2. Vercel сам определит Vite-проект (Framework Preset: Vite).
   Build command: `npm run build`, Output directory: `dist` — заполнится автоматически.
3. Нажать **Deploy**. Файл `vercel.json` уже настроен для корректной работы
   роутинга (react-router) на всех страницах.

## Депозит / оплата и бесконтактный доступ (страница `/deposit`)

Логика тарифов лежит в `src/data/deposits.ts`:

| Тариф  | Срок      | Цена/сутки | Скидка | Бонусы |
|--------|-----------|-----------:|-------:|--------|
| Неделя | 7 суток   | 1 400 ₽    | 5%     | 50 очков |
| Месяц  | 30 суток  | 1 250 ₽    | 12%    | 300 очков + скидка 10% на FFF |
| Год    | 365 суток | 950 ₽      | 25%    | 4000 очков + безлимит игрового модуля + 1 рацион FFF/день |

Поток доступа:
1. Гость выбирает срок депозита и оплачивает его целиком.
2. После оплаты бэкенд должен выпустить подписанный токен доступа
   (в текущей версии `src/components/QRCheckIn.tsx` генерирует токен
   на клиенте для демонстрации формата — **для продакшена токен должен
   приходить с сервера** после подтверждения платежа, с ограниченным
   сроком действия).
3. Токен кодируется в QR-код и показывается гостю в личном кабинете/письме.
4. На входе в сектор гость подносит QR к считывателю у турникета —
   происходит бесконтактное заселение без участия администратора.

### Что нужно подключить для реального приёма оплаты

Сейчас формы (`Booking.tsx`, `Deposit.tsx`) — это готовый UI без реального
платёжного бэкенда. Чтобы принимать деньги по-настоящему, нужно добавить
один из вариантов:
- ЮKassa / CloudPayments / Т-Кассы — для приёма карт и СБП в РФ
- Собственный API (Node/Express, Supabase, Firebase) — для хранения
  бронирований, статусов оплаты и выдачи подписанных QR-токенов
